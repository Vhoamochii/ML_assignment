# Machine Learning Project (CO3117)

## 1. Introduction

Within the scope of the Machine Learning course, the project is an important component that helps students apply learned theories and techniques to real-world problems. The objective of the project is to develop the ability to build and deploy machine learning models, covering data processing, algorithm selection, model training, and performance evaluation and improvement. 

Through this process, students will master the steps of a complete machine learning pipeline: raw data preprocessing, feature selection, model selection, hyperparameter tuning, and evaluation using various metrics (accuracy, precision, recall, F1-score, RMSE, etc.). The project also encourages students to think creatively, experiment with multiple methods, and solve problems practically. The project focuses on the correct and knowledgeable application of learned machine learning techniques, and does not require overly complex models or results that exceed State of the Art (SOTA).

## 2. Content Requirements

Each group of students needs to complete the following steps:

1. **Dataset Selection:** Choose a suitable dataset (can be from the suggested list or other sources, but must contact the instructor for approval if unsure). Students need to describe why this dataset is appropriate for ML application and identify the main challenges of the data.
2. **Problem Analysis:** Analyze the problem and explore data characteristics: data types, number of samples, distribution, and potential challenges.
3. **Algorithm Application:** Apply at least 2 different machine learning algorithms (e.g., Decision Tree, SVM, Random Forest, Logistic Regression, Neural Networks, Gradient Boosting, etc.) to solve the problem.
4. **Experimentation and Evaluation:** Conduct experiments, compare, and analyze the results of the chosen methods. Metrics must be carefully selected. Students need to explain *why* they chose a specific metric, rather than just reporting the numbers.
5. **Advanced Techniques (Optional):** If possible, experiment with advanced techniques such as feature selection, hyperparameter tuning, ensemble learning, or use a Deep Learning (DL) baseline for comparison.
6. **Report Writing:** Write a summary report clearly presenting the objectives, methods, results, discussion, and conclusion.
7. **Presentation Preparation:** Prepare presentation slides (some groups will be selected to present in class).

### Recommended Report Outline (Optional):
*   Problem Introduction
*   Data & Preprocessing
*   Models & Methods
*   Experiments & Results
*   Discussion
*   Conclusion & Future Work

## 4. Submission and Other Notes

### 4.1 Submission

*   Compress the entire assignment directory (source code, data, models, report, slides, Dockerfile if any) into a single file formatted as `StudentID1-StudentID2-....zip` (include the full list of group members' Student IDs).
*   The submission folder must include a `README.md` file describing how to run the code, the environment setup, and any necessary notes.
*   It is highly encouraged to attach a Dockerfile or virtual environment files (`environment.yml`, `requirements.txt`) to easily reproduce the results. Instructors will run the code when necessary to verify reproducibility.
*   To prevent the submission file from exceeding the allowed size limit, large files (data, models, etc.) should be separated by uploading them to a shared drive (Google Drive, Github, etc.) and including the public link in your submission.

### 4.2 Limitations and Academic Integrity

*   **Group Work:** This is a group assignment; all members must actively participate and contribute.
*   **Libraries:** The use of open-source libraries is allowed, but you cannot use commercial APIs to replace the entire pipeline.
*   **Plagiarism:** Sharing or copying code between groups is strictly prohibited. Any form of cheating will be handled according to academic regulations.
*   **AI Usage:** Using AI for reference, explanation, and debugging is allowed. Copying an entire report or code snippet without understanding it is strictly prohibited. Students are fully responsible for the submitted content.
